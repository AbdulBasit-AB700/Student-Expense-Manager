# Student Expense & Budget Manager

A beginner-friendly Student Expense and Budget Manager built with Python.

## 📌 About the Project

This is a command-line application developed using Python.

The project helps students manage their budget and keep track of their daily expenses.

It was created as a Python learning project to practice programming fundamentals and file handling.

## 🚀 Features

- Set a budget
- Add expenses
- View expense history
- Calculate total expenses
- Check remaining balance
- Find highest expense
- Store expenses permanently in a file
- Input validation
- Handles invalid user input

## 🛠️ Technologies Used

- Python
- File Handling
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling
